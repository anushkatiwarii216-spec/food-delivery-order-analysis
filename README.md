Food Delivery Data Analysis

Project Overview

This project is based on Food Delivery Customer Data Analysis using Python and Pandas. It helps to explore customer information, search customer records based on age, and analyze customer feedback.

Objectives

- To load and analyze food delivery customer data.
- To display the first N customer records.
- To search customers using their age.
- To display customer details such as age, gender, occupation, and feedback.
- To perform basic data analysis.

Technologies Used

- Python
- Pandas
- Google Colab
- CSV Dataset

Dataset

The project uses a Food Delivery Dataset stored in a CSV file named "online food delivery dataset.csv".

The dataset contains customer-related information such as:

- Age
- Gender
- Occupation
- Feedback

Features

1. View Customer Records: The user enters how many customer records they want to see.

2. Search by Age: The user enters a customer's age to find matching records.

3. Customer Details: Displays age, gender, occupation, and feedback of matching customers.

4. Basic Analysis:
   
   - Total number of customers
   - Average customer age
   - Customer feedback count

How to Run the Project

1. Download the project repository.
2. Upload the CSV dataset to Google Colab.
3. Make sure the dataset file path is correct.
4. Open the Python notebook in Google Colab.
5. Run the code.
6. Enter the number of customer records.
7. Enter the customer's age to view matching records.

Conclusion

This project demonstrates how Python and Pandas can be used to analyze food delivery customer data, retrieve customer information, and understand customer feedback through basic data analysis.
